      Import a profile

      Drop a profile — NCP .ini, Sophos Connect .scx or legacy Sophos .tgb — into the profiles directory and it appears here automatically. The desktop app scans the profiles folder and interprets each file on the fly — the pre-shared key is read into memory only when you connect, never copied to disk.

      A Sophos .pro is not a profile: it points at your user portal, and you sign in there to download the .scx to import.
